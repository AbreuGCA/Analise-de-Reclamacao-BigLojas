## **Escopo** 
Este projeto visa realizar uma consultoria analítica para dos dados adquiridos do ReclameAqui da rede de BigLojas. O objetivo é realizar ETL dos dados brutos em inteligência de mercado, identificando padrões comportamentais, falhas e oportunidades de melhorias na experiência do cliente.

A proposta abrange desde a arquitetura e higienização dos dados (Limpeza de strings, tratar dados nulos e engenharia de atributos) até  por fim na criação de uma DashBoard interativa em StreamLit, focado na tomada de decisão estatégica.

## **Tecnologias Utilizadas**
- Linguagem: Python
- Processamento de dados: Pandas, NumPy
- Ambiente de Desenvolvimento:: Jupyter NoteBook/ VS Code
